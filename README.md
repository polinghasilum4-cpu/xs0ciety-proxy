# xs0ciety API Proxy (lengkap)

Key hanya di Environment Variable: XS_API_SECRET

## Target (sesuai folder API kamu)

Instagram: instagram, twitter, pinterest, pxbee, qr, faceswap-video
SoundCloud: soundcloud, faceswap, voice, voice-changer, upload, iqc, savefrom, mail
Spotify: spotify

## Contoh
GET /api/proxy?target=instagram&url=...
POST /api/proxy?target=pxbee
